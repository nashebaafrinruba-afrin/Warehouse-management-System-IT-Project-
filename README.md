# Warehouse-management-System-IT-Project-
Warehouse Management System built with PHP, MySQL, Bootstrap and XAMPP. Automates receiving, inventory, storage, order processing, picking, packing, shipping and returns, with a KPI dashboard and role-based access for each type of warehouse staff. CSE 495 team project, East West University.
This project focuses on the analysis, design, and development of a Warehouse Management System (WMS) as part of the CSE 495 IT Project. It follows a structured software development approach, covering project planning, requirement analysis, system design, database development, module implementation, and testing. The project aims to develop a reliable and efficient solution for managing warehouse operations while applying software engineering principles and project management practices.
